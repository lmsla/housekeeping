## 2. 認證與授權

### 2.1 ES 認證

**配置** (`setting.yml`):
```yaml
url: "https://localhost:9200"
username: "elastic"
password: "changeme"
```

**建議**:
- 使用專用帳號（非 elastic superuser）
- 定期輪換密碼
- 生產環境使用 Keystore 或 Secret Management

### 2.2 必要權限

| 權限 | 用途 |
|------|------|
| `indices:admin/delete` | delete_indices |
| `indices:admin/close` | close |
| `indices:admin/open` | open |
| `indices:admin/forcemerge` | forcemerge |
| `indices:admin/settings/update` | allocation |
| `indices:admin/rollover` | rollover |
| `cluster:monitor/health` | health checks |
| `indices:admin/create` | 日誌寫回 ES (如啟用) |

## 3. Production Safety Checklist

### 3.1 Configuration Safety

- [ ] **所有 delete_indices** 都配置了 pattern filter
- [ ] **space/water_level** 都配合 pattern 使用
- [ ] 無禁止的 filter 組合 (age+space, age+water_level, space+water_level)
- [ ] Pattern filter 夠精確（避免 `.*` 或 `.` 等過於寬鬆的 pattern）

- [ ] Log path 可寫入且有足夠磁碟空間

- [ ] Test Mode 驗證完成（`test_mode: true`）
- [ ] 確認匹配的索引列表符合預期

## 4. 部署指南

### 4.1 部署方式

**方式 1**: RPM/DEB 安裝
```bash
# Ubuntu/Debian
dpkg -i bimap-housekeeping_<version>.deb
systemctl enable bimap-housekeeping
systemctl start bimap-housekeeping

# CentOS/RHEL
rpm -ivh bimap-housekeeping-<version>.rpm
systemctl enable bimap-housekeeping
systemctl start bimap-housekeeping
```

**方式 2**: 手動部署
```bash
# 1. 編譯
cd housekeeping
go build -o bimap-housekeeping ./cmd/housekeeping

# 2. 部署
sudo cp bimap-housekeeping /usr/local/bin/
sudo cp setting.yml /etc/bimap-housekeeping/
sudo cp config.yml /etc/bimap-housekeeping/

# 3. 創建 Systemd Service
sudo cp bimap-housekeeping.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable bimap-housekeeping
```

### 4.2 Systemd Service 配置

```ini
[Unit]
Description=BiMAP Housekeeping - ES Index Lifecycle Management
After=network.target

[Service]
Type=simple
User=bimap
Group=bimap
WorkingDirectory=/etc/bimap-housekeeping
ExecStart=/usr/local/bin/bimap-housekeeping
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

**關鍵參數**:
- `WorkingDirectory`: 必須包含 `setting.yml` 和 `config.yml`
- `Restart=always`: 確保服務自動重啟

## 6. 監控與維運

### 6.1 日誌監控

**位置**:
```
/var/log/bimap-housekeeping/housekeeping_YYYYMMDD.log
/var/log/bimap-housekeeping/housekeeping_detail_YYYYMMDD.log
```

**監控關鍵字**:
- `🚨 CRITICAL` - 系統 index 保護觸發
- `❌` - 操作失敗
- `✅` - 操作成功

## 7. Troubleshooting

### 7.1 配置驗證失敗

**症狀**: 程式啟動立即退出，錯誤訊息顯示配置問題

**解決**:
```bash
# 檢查錯誤訊息
./bimap-housekeeping 2>&1 | grep "配置驗證失敗"

# 常見錯誤:
# 1. delete_indices 無 pattern → 添加 pattern filter
# 2. space 無 pattern → 添加 pattern filter
# 3. 互斥組合 → 移除衝突的 filter
```

### 7.2 系統 Index 保護觸發

**症狀**: 日誌出現 `🚨 CRITICAL: Attempting to delete SYSTEM indices`

**原因**:
- Pattern 過於寬鬆 (`.*` 或 `.`)
- Regex 匹配到系統 index

**解決**:
- 使用更精確的 pattern
- Test Mode 驗證匹配結果

### 7.3 無索引匹配

**症狀**: Action 執行但無索引被操作

**可能原因**:
1. Pattern filter 不匹配任何索引
2. Age filter 條件不符
3. 系統 index 被自動排除（這是正常的）

**檢查**:
```bash
# 1. Test Mode 查看匹配
test_mode: true

# 2. 檢查 ES 實際索引
curl -X GET "localhost:9200/_cat/indices/logs-*?v"

# 3. 調整 pattern 或 age 條件
```
