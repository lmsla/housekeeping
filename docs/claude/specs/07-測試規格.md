## 1. 測試策略概述

BiMAP Housekeeping 採用**多層次測試策略**，確保系統在各種場景下的穩定性與安全性。

### 1.1 測試金字塔

```
              ┌─────────────────┐
              │  E2E 測試       │  手動/自動（測試環境驗證）
              │  End-to-End     │
              └─────────────────┘
                     ▲
                     │
              ┌─────────────────┐
              │  集成測試        │  自動化（CI/CD）
              │  Integration    │
              └─────────────────┘
                     ▲
                     │
              ┌─────────────────┐
              │  單元測試        │  ✅ 自動化（go test）
              │  Unit Tests     │  21 個測試案例
              └─────────────────┘
```

### 1.2 測試層級

| 層級 | 覆蓋範圍 | 測試工具 | 執行頻率 | 當前狀態 |
|------|---------|---------|---------|---------|
| **單元測試** | 函數/模組邏輯 | `go test` | 每次提交 | ✅ 21/21 通過 |
| **集成測試** | 組件互動 | `go test` + Mock ES | 每次提交 | 🟡 部分覆蓋 |
| **系統測試** | 完整系統 | 測試環境 | 每次發布前 | ⏸️ 待執行（Task 3.3） |
| **驗收測試** | 業務場景 | 生產模擬環境 | 每次發布前 | ⏸️ 待規劃 |

## 3. 測試環境

### 3.1 開發環境測試

**要求**:
- Go 1.23.4 或更高版本
- Elasticsearch 7.x 或 8.x（可選，用於集成測試）

**執行命令**:
```bash
# 所有單元測試
cd es-curator
go test ./... -v

# 特定模組測試
go test ./utils -v
go test ./job -v

# 查看覆蓋率
go test ./... -cover

# 詳細覆蓋率報告
go test ./... -coverprofile=coverage.out
go tool cover -html=coverage.out
```

### 3.2 測試環境驗證（E2E）

**詳細計劃**: 參考 [測試環境驗證計劃_3.3.md](../測試環境驗證計劃_3.3.md)

#### 3.2.1 環境需求

```yaml
Elasticsearch:
  版本: 7.x 或 8.x
  節點數: 至少 1 個
  狀態: Green 或 Yellow
  可用磁碟空間: > 10 GB

測試數據:
  系統 Index: .kibana, .security, ilm-history-*, etc.
  測試 Index: logs-test-*, metrics-test-*, etc.
```

#### 3.2.2 測試場景

**Layer 4 驗證**（配置驗證）:
- [ ] delete_indices 無 pattern → Fail Fast
- [ ] space 無 pattern → Fail Fast
- [ ] water_level 無 pattern → Fail Fast
- [ ] age + space → Fail Fast
- [ ] age + water_level → Fail Fast
- [ ] space + water_level → Fail Fast

**Layer 1 驗證**（Pattern Filter）:
- [ ] `.kibana` 被自動排除
- [ ] `.security` 被自動排除
- [ ] `ilm-history-*` 被自動排除
- [ ] 正常 index 正確匹配

**Layer 2 驗證**（Filter Combination）:
- [ ] pattern + space 正常工作
- [ ] pattern + water_level 正常工作
- [ ] 單獨 space 被拒絕
- [ ] 單獨 water_level 被拒絕

**Layer 3 驗證**（Delete Action Protection）:
- [ ] 嘗試刪除系統 index → 操作中止
- [ ] 刪除正常 index → 操作成功
- [ ] 日誌記錄完整

**End-to-End 測試**:
- [ ] Test Mode 預覽正確
- [ ] 實際執行符合預期
- [ ] Metrics 記錄完整
- [ ] 日誌回寫 ES 成功

### 3.3 CI/CD 集成

**當前狀態**: 🟡 待建立

**建議設置**:
```yaml
# .github/workflows/test.yml 範例

name: Go Tests

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main, develop ]

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v3

    - name: Set up Go
      uses: actions/setup-go@v4
      with:
        go-version: '1.23.4'

    - name: Run Unit Tests
      run: |
        cd es-curator
        go test ./... -v -race

    - name: Generate Coverage Report
      run: |
        cd es-curator
        go test ./... -coverprofile=coverage.out
        go tool cover -func=coverage.out
```

## 5. 測試自動化

### 5.1 本地測試腳本

**創建測試腳本** `scripts/run_tests.sh`:
```bash
#!/bin/bash

set -e

echo "=== BiMAP Housekeeping 測試套件 ==="
echo

# 1. 單元測試
echo "▶ 執行單元測試..."
cd es-curator
go test ./... -v

# 2. Race Detector
echo
echo "▶ 執行 Race Detector..."
go test ./... -race

# 3. 覆蓋率報告
echo
echo "▶ 生成覆蓋率報告..."
go test ./... -coverprofile=coverage.out
go tool cover -func=coverage.out

# 4. 靜態分析
echo
echo "▶ 執行靜態分析..."
go vet ./...
golint ./...

echo
echo "✅ 所有測試通過！"
```

**使用方式**:
```bash
chmod +x scripts/run_tests.sh
./scripts/run_tests.sh
```
