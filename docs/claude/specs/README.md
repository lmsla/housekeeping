## 🔍 系統簡介

**BiMAP Housekeeping** 是一個用 Go 語言開發的 Elasticsearch 索引生命週期管理服務，自動化執行索引操作如刪除、分層配置（hot/warm/cold）、force merge、rollover 等，基於可配置的過濾器（age、pattern、space、water level）。

### 核心功能

1. **索引生命週期管理** 🗂️
   - 自動刪除過期索引
   - Hot→Warm→Cold 分層遷移
   - 索引 Rollover 管理

2. **安全防護機制** 🔒
   - 四層防禦架構
   - 系統 Index 黑名單保護
   - Fail Fast 配置驗證

3. **監控與日誌** 📊
   - 本地 Metrics 收集
   - Cluster Health 即時監控
   - Shard 限制告警
   - 日誌回寫 ES

4. **靈活配置** ⚙️
   - YAML 配置文件
   - 多種 Filter 組合
   - Test Mode 預覽
   - Cron 排程執行

### 技術堆疊

| 層級 | 技術 | 版本 |
|------|------|------|
| 語言 | Go | 1.23.4 |
| 存儲 | Elasticsearch | 7.x / 8.x |
| 部署 | Systemd Service | - |
| 打包 | RPM / DEB | - |
| 日誌 | Zap (structured logging) | - |
