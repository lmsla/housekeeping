# BiMAP Housekeeping - 詳細問題清單

## 嚴重問題 (Severity: Critical)

### Issue #1: TLS證書驗證被禁用
- **編號**: CRIT-001
- **檔案**: `/es-curator/job/job.go`
- **行號**: 26-28
- **類別**: 安全性 (Security)
- **影響**: 中間人攻擊 (MITM) 風險
- **修復難度**: ⭐ (簡單)
- **修復時間**: 30分鐘
- **優先級**: 🔴 最高

**詳細描述**:
```go
Transport: &http.Transport{
    TLSClientConfig: &tls.Config{InsecureSkipVerify: true},
},
```
禁用HTTPS證書驗證，憑證可被截獲，Elasticsearch服務器身份無法驗證。

**修復方案**:
1. 加載CA證書文件
2. 使用配置的CA路徑
3. 移除 InsecureSkipVerify

### Issue #2: JSON解析錯誤被忽略
- **編號**: CRIT-002
- **檔案**: 
  - `/es-curator/job/indices.go` (行 162, 189)
  - `/es-curator/job/nodes.go` (行 50)
- **類別**: 可靠性 (Reliability)
- **影響**: 數據損壞、靜默失敗
- **修復難度**: ⭐ (簡單)
- **修復時間**: 1-2小時
- **優先級**: 🔴 最高

**詳細描述**:
```go
json.Unmarshal(resString, &s)  // 錯誤被忽略
```

**修復方案**:
```go
if err := json.Unmarshal(resString, &s); err != nil {
    global.Logger.Error("JSON解析失敗", "error", err)
    return
}
```
