## 🛠️ 修復示例

### 示例1: 修復TLS驗證

**原始代碼**:
```go
Transport: &http.Transport{
    TLSClientConfig: &tls.Config{InsecureSkipVerify: true},
},
```

**修復後**:
```go
// 加載CA証書
caCert, err := os.ReadFile(global.EnvConfig.INFORMATION.CaPath)
if err != nil {
    return err
}
caCertPool := x509.NewCertPool()
caCertPool.AppendCertsFromPEM(caCert)

cfg := elasticsearch.Config{
    Addresses: global.EnvConfig.ES.URL,
    Username:  global.EnvConfig.ES.SourceAccount,
    Password:  global.EnvConfig.ES.SourcePassword,
    Transport: &http.Transport{
        TLSClientConfig: &tls.Config{
            RootCAs: caCertPool,
        },
    },
}
```

### 示例2: 修復JSON錯誤

**原始代碼**:
```go
json.Unmarshal(resString, &s)
```

**修復後**:
```go
if err := json.Unmarshal(resString, &s); err != nil {
    global.Logger.Error("解析響應失敗", 
        "error", err.Error(),
        "responseBody", string(resString))
    return
}
```
