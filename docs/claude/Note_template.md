# 學習筆記模板

**用途**: 此模板用於記錄開發過程中遇到的重要技術概念和學習心得
**目標讀者**: 開發團隊成員、AI 助手、未來的自己
**更新頻率**: 每當遇到重要技術概念或疑難問題時

---

## 模板使用說明

### 📋 何時使用此模板

**適合記錄的內容**：

- ✅ 開發過程中遇到的技術疑問及解答
- ✅ 容易混淆的概念（如 Panic vs Error）
- ✅ 重要的最佳實踐和設計模式
- ✅ 踩過的坑和解決方案
- ✅ 需要反覆查閱的技術細節

**不適合記錄的內容**：

- ❌ 簡單的 API 使用說明（應查官方文檔）
- ❌ 臨時性的 bug 修復筆記（應記錄在 Git commit）
- ❌ 項目管理相關內容（應記錄在項目管理工具）

### 🎯 模板結構說明

每個議題包含以下核心章節：

1. **問題背景** - 記錄為什麼會有這個疑問
2. **核心概念** - 解釋基本概念和定義
3. **關鍵理解** - 深入分析和實際案例
4. **實際代碼分析** - 使用項目中的真實代碼
5. **對比說明** - 使用表格對比不同概念
6. **實際場景** - 展示問題發生的時間軸
7. **解決方案** - 提供可操作的修復方法
8. **修復前後對比** - 展示改進效果
9. **學習要點** - 提煉核心知識
10. **最佳實踐** - 給出可遵循的規則
11. **相關資源** - 鏈接到官方文檔和文章
12. **實踐建議** - 立即可行動的建議
13. **總結** - 用一句話概括核心觀念

### 📝 模板填寫指南

#### 必填字段（⭐ 標記）

- 問題背景
- 核心概念
- 關鍵理解
- 實際代碼分析
- 解決方案
- 總結

#### 選填字段

- 特殊情況分析（如果有）
- 視頻教程（如果有）
- 相關議題索引（如果有）

#### 代碼示例規則

1. 使用項目中的真實代碼
2. 標註文件路徑和行號
3. 使用 ✅ 和 ❌ 標記正確/錯誤
4. 使用 💥 標記危險/問題點
5. 添加註釋說明關鍵點

#### 表格使用規則

1. 用於對比不同概念
2. 用於展示修復前後效果
3. 用於列出檢查清單
4. 保持表格簡潔（≤5列）

#### 時間軸格式

```
時間/步驟 - 描述 [狀態標記]
```

- 使用 ✅ 表示正常
- 使用 ❌ 表示失敗
- 使用 💥 表示關鍵問題點
- 使用 ⚠️ 表示警告
